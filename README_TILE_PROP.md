# Tile / Prop rebuild v1

This branch now contains two distinct experiments:

1. `generated/` is the old crop/mask extraction experiment. It is useful only as a cautionary baseline.
2. `redraw/` is the real rebuild: assets are drawn from blank canvases, converted to native Pixelorama `.pxo`, and validated through Pixelorama CLI export/split-layer export.

## Current validated redraw set

- `redraw/lamp_post/`
- `redraw/tree_round/`
- `redraw/stone_tiles_32/`
- `redraw/blue_banner/`
- `redraw/fountain/`

The next execution phase is generated by `scripts/build_phase3_5.py`: market stalls/modules, terrain border tiles, extra vegetation and a larger reassembly proof.

See `ROADMAP.md` for the complete plan and acceptance criteria.

# Economy Rule Lab / 国王经济模拟压力测试

独立 Node.js 模拟，不覆盖现有游戏代码。无第三方依赖。

```bash
node economy-lab/sim.js
node economy-lab/test.js
node economy-lab/payroll.js
node economy-lab/payroll-test.js
node economy-lab/calibrate.js
```

## 当前设计边界

- NPC只持有金币、饱食、SAN、物品；个人效用权重 α/β/γ 及投资折现参数 δ。
- 当前物品价格可知，行动投入、产出、工时、建筑寿命可知。
- 无未来价格预测、隐藏订单、预测销量和NPC主观商品估值。
- 生产是实际投入产出；买卖改变买卖双方的金币和物资所有权。
- 本仓库只是**法则验证沙盒**，不是完整游戏运行时。

## 更新后的唯一物价调整公式

```text
P(t+1) = P(t) * [1 + k*(D - S)/(D + S + 1)],  k = 0.2
```

D 是当前价格下愿意且买得起的需求量，S 是本轮可供出售的库存。D=S 时不变；D>S 涨；D<S 跌；D=0 与 S=0 均可计算，正价格不会单轮归零。零库存但有有效需求时价格可上升。

没有价格地板、特定商品的调价规则，也没有“价格向目标值回归”。

## 原始情景再测试（单轮）

| 情景 | 结果 |
|---|---|
| 面包短缺 D=20、S=8 | 5 → 5.4138 |
| 面条加入竞争 | 面包需求20 → 10、面条需求10；面包新价格4.9130 |
| 生产力：每轮产出12 → 36 | 面包新价格5.2424 → 4.7193 |
| 给原本买不起面包的人额外金币 | 面包需求5 → 20；单轮新价格4.6111 → 5.2424 |
| 给已经富裕的NPC更多金币 | 需求不变20 → 20，**并不自动涨价** |
| 仅因为涨价而囤面包 | 无预期价格，买入持有不增加即时效用，**不发生** |
| 当前价格升高是否想开店 | 当前产出折算价值足够高时偏好开店；**未真的进行投资和开业** |

**长期压力测试：**原来在第二天跌到0的面包价格不再归零。但在没有工资流转的旧原型里，30轮后价格仍跌至约 **0.0121**。这不是数值错误；钱从消费者流向商人后没有再流回消费者。

## 根据提供的建筑配方新增工资实验

`payroll.js` 保存以下6个建筑的建造材料/人力时、工作SAN消耗和每人力时的物资投入产出：
磨房、农田、水稻田、面包房、沙地、铁矿场。建造成本当前仅作为**配方数据**保存，尚未实现建筑自动建造。

重点验证面包房：每工作1小时，工人损失10SAN并从**建筑所有者**获得时薪；面包房消耗2电、1水、1面粉，增加2个面包。工人比较“工作获得工资”与“休息恢复SAN”的效用，只在前者更有价值、雇主付得起工资且配方可盈利时受雇。

**面包房工资测试初始条件**：1个持有100金币的店主 + 4个初始0金币的工人；每人初始60饱食、80SAN；面包初始价5，面包恢复40饱食，饱食每小时-10，休息SAN+10/h。α=1，β=3，γ=0.1。起始面包房拥有100面粉及必要水电作为**有限的初始库存**。每轮至多1个工人操作面包房。金币总量始终100。

| 时薪 | 运行时长 | 实际上班小时数 | 支付工资 | 面包销量 | 期末价格 | 期末饱食为0的人数 |
|---|---:|---:|---:|---:|---:|---:|
| 0 | 30h | 0 | 0 | 0 | 87.247 | 5/5 |
| 3 | 30h | 24 | 72 | 47 | 2.689 | 1/5 |
| 6 | 30h | 30 | 180 | 59 | 4.832 | 0/5 |
| 6 | 60h | 60 | 360 | 120 | 4.967 | 0/5 |
| 6 | 120h | 100 | 600 | 200 | 39.097 | 5/5 |

“饱食为0”不意味着已经实现死亡事件；这里只追踪数值。

**关键结论：**

1. 没有人愿意无工资工作，面包不能生产，消费者最终饱食归零；这是合理的经济后果，不应该通过自动注资修复。
2. 时薪6的前60小时可维持工作、销售、消费，价格围绕5附近波动，说明价格无需被硬性锚定。
3. **120小时不稳定**：初始100面粉被用尽后，面包房停止产出，工资停止流转，物价上涨和饥饿再次出现。当前没有真正运行农田→磨房→面包房的原料供给闭环，**不能宣称已经实现长期均衡**。
4. 工作工资与销售额均只在主体之间转移；测试中总金币始终为100。

## 参数调试原则

- `k=0.2` 影响调价速度；不会修复缺乏工作、原料或有效需求的问题。
- α/β/γ决定金钱、饱食和SAN之间的相对偏好。**它们同时乘以同一个正数时行为不变**；可以固定α=1，仅调β/α、γ/α。
- δ只进入长期投资的折算；不影响这里的即时食物消费和工资测试。
- 时薪是可计算的劳动价格，并非凭空创造货币。雇主如果没有金币，就无法付薪。
- 实验中的现实约束包括原料有限、工作岗位有限、收入可能不均。这些会导致失业与经济崩溃，不应为了曲线平稳被自动修正。

## 尚未实现

- 全部建筑真实建造过程，以及可持续的农田→磨房→面包房生产与采购交易；
- 自动创建/倒闭企业、完整NPC职业选择、土地与税收；
- 由于没有未来价格估计，自发投机囤货不能出现。

先把资源生产链、真实付薪和消费闭环验证后，再决定是否校准 k 和 NPC 的偏好权重。

## NPC偏好与工资敏感性测试（60小时）

`calibrate.js` 只调整已存在的个人效用参数及工资，对135组设定重复执行同一算法。每组都沿用初始有限面粉库存，所以属于有限时段的敏感性实验，而不是长期均衡证明。

| 时薪 | α | β | γ | 最后30小时均价 | 价格波动CV | 有NPC饱食归零？ |
|---:|---:|---:|---:|---:|---:|---|
| 3 | 1 | 3 | 0.1 | 2.8788 | 0.0340 | 是 |
| 4 | 1 | 3 | 0.1 | 3.9330 | 0 | 否 |
| 6 | 1 | 3 | 0.1 | 4.9557 | 0.0371 | 否 |
| 4 | 2 | 3 | 0.1 | 3.4549 | 0.0704 | 是 |

135组中，**83组**在60小时内没有NPC饱食归零且累计完成至少50小时工作。这个统计不是“合格参数”的权威标准，只是对同一初始条件的试验筛选。

**参考初值**：暂时固定 α=1、β=3、γ=0.1、δ=0.97；模拟工资时可先试4金币/小时，然后换不同NPC个性权重观察结果。只有效用权重之间的比例影响选择（整体同比例缩放不变），因此不必同时标定3个独立尺度。

**重要限制：**时薪4的价格在30～60小时确实停在3.933，但在100份初始面粉耗尽后，120小时的价格上涨至26.459，所有5个NPC饱食为0。这说明不能仅靠调工资或效用参数保证永久均衡；必须先把你给出的农田→磨房→面包房原料链完整接通。

## 120小时：六建筑+自主投资+真实交易+人口迁入的完整环节试验

运行：

```bash
node economy-lab/integrated.js > economy-output.json
node economy-lab/integrated-test.js
```

源代码：[integrated.js](./integrated.js)；断言：[integrated-test.js](./integrated-test.js)；实际数据：[integrated-results.json](./integrated-results.json)。

**人口规则：**每轮生产、市场购买、消费结束后，如果 `可出售面包库存+可出售水稻库存 >= 0.5 * 当时人口`，就迁入1名NPC；每轮最多1名。迁入者初始金币0，饱食65，SAN85，和原NPC使用同一个效用与就业选择。0.5是本轮的可调场景参数，不是由经济理论推出的唯一阈值。

**运行环节：**六种建筑以用户给定的确定配方每小时实际生产；雇主扣除工资、工人收到工资并损失SAN；磨房向农田购买大麦，面包房向磨房购买面粉，居民比较面包/水稻的食用效用并向商家付款；NPC用**当前**商品价格和原有折现年金公式评估是否投资新建筑，真正支付建材、招工并完成建造。供需反馈统一使用 `P'=P*(1+0.2*(D-S)/(D+S+1))`。

**原料限制：**由于未提供木材、水、电的生产配方，本实验只把它们作为**有限的初始资源库存**。它们在此试验里没有市场生产者且参考单价为0；消耗实际扣除库存，不能凭空补充。因此这不是可以无限运行的自给自足国家，也没有独立实现薪酬议价、国债、生产技术研究、房价、自然死亡或税收。

### 120小时对照（相同随机性：确定性运行）

| 指标 | 不允许迁入 | 库存达到人口0.5倍时允许迁入 |
|---|---:|---:|
| 初始人口 | 15 | 15 |
| 最终人口 | 15 | 22 |
| 新迁入人口 | 0 | 7 |
| 第一名移民 | - | 第15小时，库存8 |
| 完工新增建筑 | 19 | 18 |
| 总建筑 | 25 | 24 |
| 生产大麦 | 31 | 28 |
| 生产面粉 | 28 | 27 |
| 生产面包 | 56 | 54 |
| 生产水稻 | 681 | 681 |
| 饱食值归零人数 | 2 | 9 |
| 总金币 | 567 | 567 |

另外水泥、铁矿也发生生产，两个场景分别都生产8水泥和8铁矿；所有交易与薪资都真实转账，总金币没有变化。房屋建造消耗的建材、工具类建造配方按已知投入执行，建造同样需要支付施工工资。

**重要的结果，不是bug遮掩：**在允许移民的情景里，第120小时有9名NPC饱食为0，包括3名移民；同时面包生产因经济决策中断，大麦市场价已跌至约0.00038，新增的18座建筑里大多数是农田。短期按现价有利可图，长期却出现农田过度投资、原料链失衡和就业不足——是没有未来销量估计的既有模型的固有限制。食品仍可有库存，但没有工资或买不起的人仍可能挨饿。

### 移民门槛敏感性

同样120小时，其他参数不变：

| 迁入门槛（现存食品/人口） | 新移民 |
|---:|---:|
| 0.3 | 18 |
| 0.5 | 7 |
| 1.0 | 0 |

将每小时价格响应系数和时薪组合测试时，结果高度敏感：例如时薪3，`k=0.05` 时120小时后总人口76、饱食为0人数76；而 `k=0.2` 时总人口22、饱食为0人数9。**不能通过找到一组“看起来平稳”的参数就声称整个模型长期成立**，应先确定生产、就业、交易、投资和人口之间的反馈是否符合你的设计目标。

### 已验证 / 未验证

- **已验证：**大麦→面粉→面包、稻米、铁矿和水泥真的在同一小时循环中生产；NPC付钱买货、领取工资、休息恢复SAN；物价随当前有效供需变化；商品与金币不凭空出现；自发投资消耗建材并建成建筑；食品余量可以触发移民。
- **尚未验证：**长期稳定均衡、长期可持续资源供应、必需品缺货时的死亡与迁出、企业倒闭/破产、自动形成足够的工作岗位。上述功能不得因为测试不成功就偷偷加入硬编码干预。

**特别注意：**当前的迁入规则只能判定物资库存充足，不能保证新来的人有收入。这是该规则真实的运行结果，而不是模拟器漏给移民发钱。
